# 方法引用与实现范围 / References and implementation scope

以下列出集合中的 21 项模型、方法与组件。每条引用注明实际关联：算法基础、架构背景或任务适配。引用不表示采用了原作者源码或完整复现其架构。 / These 21 model/method/component entries distinguish local adaptations from separately supplied official models; references indicate algorithmic or architectural background, not copied official implementations or full reproduction.


方法根据相关任务和算法构建。本表逐项提供论文或 GitHub 引用及实际实现。部分历史 ID 与参考架构不同：例如 `convlstm`/`predrnn_style`/`strictsimvp_style` 使用 2D CNN，`convgru`/`temporal3d` 使用 MLP。任务适配不等于原论文完整复现。
